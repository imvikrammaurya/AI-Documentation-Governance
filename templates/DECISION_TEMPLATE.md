# Decision Entry Template

Use this shape for a `DECISION`-type entry in `docs/governance/PROJECT_DECISIONS.md`. See
`docs/governance/PROJECT_MEMORY.md` for when this applies vs. `PROJECT_MEMORY_ENTRY_TEMPLATE.md`.

```
### <ID> — <short title>

- **Type:** `DECISION`
- **Decision:** <the exact choice made, stated plainly>
- **Alternatives considered:** <what else was on the table>
- **Reason:** <why this option was chosen over the alternatives — quote/paraphrase the actual
  stated reasoning, never invent a plausible-sounding one>
- **Affected feature(s):** <feature/component names>
- **Affected documents:** <paths>
- **Date:** <YYYY-MM-DD>
- **Authority status:** `DECISION` — binding until superseded
- **Source:** <how this was captured — e.g. "stated directly by the user in session">
- **SUPERSEDES:** <previous entry ID, if this replaces an earlier decision — omit if none>
```

Only capture this from an **explicit** statement ("we decided X," "the final approach is X") —
never from a hypothetical or an in-progress brainstorm.
